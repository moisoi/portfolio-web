# Messay Mohammed — Portfolio

A recruiter-focused, dependency-free personal portfolio for **Messay Mohammed**, a Full Stack & Mobile Developer based in Addis Ababa, Ethiopia.

## Run locally

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Open `http://localhost:4173`.

## Standout recruiter features

- Interactive project case studies, activated by click or keyboard
- Filterable skill matrix organised by build, data, and operations context
- Curated “Ask my portfolio” assistant answering from the résumé content only
- Command-menu navigation (`K`) and responsive mobile navigation
- Print-ready web résumé at [`resume.html`](resume.html), with **Save as PDF** action
- Scroll progress, active navigation states, accessible dialogs, keyboard support, and reduced-motion handling

The site has no package installation or build step. All portfolio content lives in `index.html`, case-study and assistant copy live in `script.js`, and visual styling lives in `styles.css`.
